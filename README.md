# Spooky

Belajar komputasi kuantum lewat visual 3D interaktif. Nama dari ucapan Einstein tentang keterikatan kuantum: _"spooky action at a distance"_.

100% client-side — tanpa backend, akun, atau pelacakan.

```bash
npm install
npm run dev
```

Dokumentasi lengkap menyusul di fase akhir; lihat `docs/progress.md`.
